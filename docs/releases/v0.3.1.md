# ArxivResearch v0.3.1

Includes the previously unpublished v0.3.0 improvements and the arXiv rate-limit fix.

## Highlights

- Fix overlapping arXiv requests from manual fetches, automatic subscription checks, and the background helper. Requests share a cross-process lock and are spaced at least 3.5 seconds apart.
- Honor Retry-After on HTTP 429/503 and persist exponential cooldowns starting at 60 seconds, preventing repeated requests during a cooldown even after restarting the app.
- Display fetch failure details and the next permitted retry time.
- Open completed deep-read reports from paper lists and recent activity, and copy the full report as Markdown.
- Cache Keychain values during the active session and refresh the installed background helper after an app update.
- Include Sparkle update controls and future Developer ID/shared Keychain release support.

## Installation

Download the macOS Apple Silicon ZIP, quit ArxivResearch, unzip it, and replace the existing app. Local papers and settings remain in Application Support.

This package is ad-hoc signed, not Apple-notarized. macOS may require **Open Anyway** in Privacy & Security. Automatic updates are disabled because this build has no configured Sparkle verification key; install this update manually. Shared Keychain access and notarization will require a future Developer ID build; existing Keychain prompts may still occur.
